# PIVOT

Site institucional da PIVOT, escola profissionalizante de Jundiaí (SP).

## Como abrir

1. Abra a pasta no VS Code.
2. Instale a extensão Live Server.
3. Clique com o botão direito em `index.html` e escolha "Open with Live Server".

Também funciona abrindo o arquivo `index.html` direto no navegador.

## Funcionalidades

- Página inicial com painel de novidades, notícias, vagas e parcerias
- Lista de cursos e página completa de cada curso
- Cadastro e login com e-mail e senha
- Área "Minha conta" com foto de perfil, dados pessoais e cursos de interesse
- Assistente virtual PVT IA para sugerir cursos

## Observações

- Os dados das contas ficam salvos no navegador (localStorage).
- As notícias, vagas, professores e depoimentos são fictícios.
